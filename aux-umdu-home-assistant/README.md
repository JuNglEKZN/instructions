# Подключение кондиционера AUX к Home Assistant через UMDU AC

Пошаговая инструкция для связки:

```text
AUX ASW-H18A4/BA-R2DI
        │ UART
        ▼
     UMDU AC
        │ Wi‑Fi / ESPHome
        ▼
  Home Assistant
```

UMDU AC подключается к штатному коммуникационному порту кондиционера и передаёт управление в Home Assistant по локальной сети. Питание кондиционера при этом не разрывается: штатный пульт продолжает работать независимо.

> [!IMPORTANT]
> Модель AUX ASW-H18A4/BA-R2DI поддерживает штатный Wi‑Fi-модуль AUX WF 002, поэтому коммуникационный порт у неё предусмотрен. Однако серия BA-R2DI не указана буквально в опубликованном перечне подтверждённых моделей UMDU. Сначала необходимо проверить полноценное управление кондиционером через UMDU и Home Assistant, и только затем переходить к монтажу настенной кнопки.

## Что потребуется

- UMDU AC в версии AUX;
- доступ к внутреннему блоку кондиционера;
- домашняя Wi‑Fi-сеть 2,4 ГГц;
- Home Assistant;
- телефон или компьютер для первичной настройки;
- доступ к интерфейсу роутера Keenetic.

## 1. Полностью обесточить кондиционер

1. Выключить кондиционер штатным пультом.
2. Отключить автомат кондиционера в электрощите.
3. Подождать несколько минут.
4. Проверить отсутствие питания.

> [!WARNING]
> Не подключать и не отключать UMDU при поданном питании кондиционера.

## 2. Найти порт штатного Wi‑Fi-модуля

1. Открыть верхнюю крышку внутреннего блока.
2. Снять фильтры, если они мешают доступу.
3. Найти штатное место установки Wi‑Fi-модуля или провод с разъёмом, внешне похожим на USB.

В кондиционерах AUX встречаются два основных варианта:

- четырёхпроводный псевдо-USB;
- пятипроводный разъём с переходником.

Четырёхпроводный разъём внешне может быть похож на USB, но передаёт питание и UART, а не обычный USB-протокол. UMDU использует линии `VCC`, `GND`, `RX` и `TX` и допускает питание в диапазоне 5–19 В.

### Стоп-условие

Остановить подключение, если разъём:

- не совпадает физически;
- имеет пять проводов;
- не подписан;
- требует самодельной распиновки;
- вызывает сомнение по полярности питания.

Нельзя подключать UMDU в обычный USB-порт компьютера или угадывать распиновку методом проб.

## 3. Перевести UMDU в режим кондиционера

На плате UMDU перевести переключатель:

```text
USB → AC
```

Положение `USB` используется для сервисного режима, положение `AC` — для UART-связи с кондиционером.

## 4. Подключить UMDU к кондиционеру

Для четырёхпроводного псевдо-USB:

1. Вставить UMDU в штатный разъём без перекоса и усилия.
2. Разместить модуль так, чтобы:
   - кабель не зажимался крышкой;
   - модуль не касался теплообменника;
   - на него не мог попасть конденсат;
   - металлические части внутреннего блока не перекрывали антенну полностью.
3. Вернуть фильтры на место.
4. Закрыть крышку внутреннего блока.

## 5. Подать питание

1. Включить автомат кондиционера.
2. Подождать до пяти минут.
3. Не выключать питание, если точка доступа UMDU не появилась в первые 30–60 секунд.

Первый запуск и инициализация встроенного веб-сервера могут занять несколько минут.

## 6. Подключить UMDU к Wi‑Fi

### 6.1. Подключиться к точке доступа UMDU

На телефоне открыть список Wi‑Fi-сетей и найти сеть UMDU AC.

Пароль точки доступа:

```text
12345678
```

Открыть в браузере:

```text
http://umduac.local
```

Для некоторых плат версии 1.1 адрес может быть:

```text
http://umduaux.local
```

Данные входа:

```text
Логин: umdu
Пароль: umdu
```

Если адрес `.local` не открывается:

1. Отключить мобильный интернет на телефоне.
2. Проверить, что телефон остаётся подключён к точке UMDU.
3. Повторить открытие страницы.
4. После подключения UMDU к домашней сети найти его IP-адрес в Keenetic.

### 6.2. Подключить к домашней сети

В веб-интерфейсе UMDU:

1. Выбрать домашнюю Wi‑Fi-сеть 2,4 ГГц.
2. Ввести пароль.
3. Сохранить настройки.
4. Дождаться перезагрузки.
5. Найти устройство в списке клиентов Keenetic.

Рекомендуемое имя:

```text
umdu-aux-livingroom
```

Рекомендуется закрепить постоянный DHCP-адрес, например:

```text
192.168.1.60
```

Фактический адрес зависит от вашей сети.

## 7. Проверить встроенный интерфейс

Открыть UMDU по закреплённому IP-адресу:

```text
http://192.168.1.60
```

Проверить, что:

- веб-интерфейс открывается;
- кондиционер определяется;
- отображаются текущий режим и температура;
- команды из интерфейса доходят до кондиционера;
- изменения со штатного пульта появляются в интерфейсе UMDU.

Не переходить к Home Assistant, пока управление из интерфейса UMDU не работает стабильно.

## 8. Добавить UMDU в Home Assistant

Открыть:

```text
Настройки
→ Устройства и службы
→ Добавить интеграцию
→ ESPHome
```

Указать:

```text
umduac.local
```

или закреплённый IP:

```text
192.168.1.60
```

После добавления переименовать основную сущность, например:

```text
climate.aux_living_room
```

Фактический `entity_id` может отличаться. Его необходимо использовать во всех дальнейших автоматизациях.

## 9. Проверить функции кондиционера

Последовательно проверить из Home Assistant:

1. Включение.
2. Выключение.
3. Режим `Cool`.
4. Режим `Heat`.
5. Изменение температуры.
6. Скорости вентилятора.
7. Качание жалюзи.
8. Обновление состояния после команд штатным пультом.

Последний пункт подтверждает двустороннюю связь, а не только отправку команд.

## 10. Записать поддерживаемые режимы

Открыть:

```text
Инструменты разработчика
→ Состояния
→ climate.aux_living_room
```

Записать значения атрибутов:

```text
hvac_modes
fan_modes
fan_mode
swing_modes
swing_mode
min_temp
max_temp
temperature
```

Пример:

```yaml
hvac_modes:
  - "off"
  - cool
  - heat
  - dry
  - fan_only
  - auto

fan_modes:
  - auto
  - low
  - medium
  - high

swing_modes:
  - "off"
  - vertical
```

Фактические названия в прошивке UMDU могут отличаться. В сценариях необходимо использовать именно реальные значения атрибутов.

## 11. Если кондиционер не отвечает

Проверить:

- переключатель UMDU установлен в положение `AC`;
- выбран протокол AUX;
- соединение с портом кондиционера;
- питание UMDU;
- направление UART `RX/TX` в веб-интерфейсе UMDU.

UMDU позволяет программно изменить направление `RX/TX`, поэтому физически переставлять сигнальные провода обычно не требуется.

Если веб-интерфейс UMDU работает, но сущность `climate` не управляет кондиционером, вероятные причины:

- неверно выбран протокол;
- несовместимость конкретной платы внутреннего блока;
- нестандартная распиновка разъёма;
- отсутствие полноценного UART-обмена.

## 12. Проброс кондиционера в Алису

В интеграции Яндекс Smart Home добавить к экспортируемым сущностям:

```text
climate.aux_living_room
```

После обновления устройств проверить команды:

```text
Алиса, включи кондиционер
Алиса, установи кондиционер на 23 градуса
Алиса, выключи кондиционер
```

Рекомендуемое имя устройства:

```text
Кондиционер
```

## Что будет работать при сбоях

| Сбой | Что останется доступно |
|---|---|
| Home Assistant выключен | Штатный пульт AUX |
| UMDU недоступен | Только штатный пульт |
| Интернет недоступен | Локальные UMDU и Home Assistant продолжают работать |
| Wi‑Fi полностью выключен | Штатный пульт AUX |
